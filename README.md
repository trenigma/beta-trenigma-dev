# BETA — Cascade Conditions Intel
**beta.trenigma.dev** (or cascades.trenigma.dev — TBD)

> Go / Wait / No-Go crag conditions for Cascade climbers.
> Built by a climber, for climbers.

---

## 🏔️ What this is

BETA is a conditions intelligence tool for rock climbers in the Pacific Northwest Cascades.
It synthesizes precipitation history, humidity, temperature, and drying time estimates into
a simple go/wait/no-go signal for key PNW crags.

Built by Tree — SRE, Rising Roots climbing community co-facilitator, and person who has
absolutely driven 2 hours to Index on wet rock before.

## 🚀 Phase 1: Get it live (You Are Here)

### Step 1 — Create your GitHub repo

1. Go to [github.com/new](https://github.com/new)
2. Name it: `beta-site` (or whatever you want the subdomain to be)
3. Make it **Public** (required for free GitHub Pages)
4. Don't initialize with README (you already have one)

### Step 2 — Push this code

```bash
cd beta-site
git init
git add .
git commit -m "Phase 1: Site skeleton live"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/beta-site.git
git push -u origin main
```

### Step 3 — Enable GitHub Pages

1. Go to your repo on GitHub → **Settings** → **Pages**
2. Under **Source**: select `Deploy from a branch`
3. Branch: `main`, Folder: `/ (root)`
4. Click **Save**
5. In ~2 minutes your site is live at `https://YOUR_USERNAME.github.io/beta-site`

### Step 4 — Connect your subdomain (beta.trenigma.dev or cascades.trenigma.dev)

**In your DNS provider (wherever trenigma.dev is registered):**
Add a CNAME record:
```
Name:  beta          (or cascades)
Value: YOUR_USERNAME.github.io
TTL:   3600
```

**In your GitHub repo:**
Create a file called `CNAME` (no extension) in the root with one line:
```
beta.trenigma.dev
```
(Or swap for `cascades.trenigma.dev` — your call)

**In GitHub Pages settings:**
Enter your custom domain in the "Custom domain" field and enable "Enforce HTTPS"

DNS propagation takes 5-30 minutes. Then it's live.

## 🌦️ Data Sources (Phase 4)

| Source | What it provides | API |
|--------|-----------------|-----|
| [Open-Meteo](https://open-meteo.com) | Precipitation, humidity, temp by lat/lng | Free, no key |
| [NWS/NOAA](https://api.weather.gov) | Point forecasts, hourly obs | Free, no key |
| [NWAC](https://nwac.us) | Avalanche danger, mountain weather | Scrape / RSS |
| [SNOTEL/NRCS](https://www.nrcs.usda.gov) | Snowpack, snowwater equivalent | Free API |
| [MesoWest](https://mesowest.utah.edu) | Surface obs from local stations | Free tier |
